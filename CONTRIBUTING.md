# Contributing Guidelines

Thank you for considering a contribution!

## How to Contribute

1. Check existing issues and pull requests to avoid duplicating work.
2. Fork the repository.
3. Create a branch for your change, for example `feature/improve-calculator`.
4. Make a focused change and test it.
5. Commit with a clear message, such as `Add input validation`.
6. Push your branch to your fork.
7. Open a pull request and explain what you changed and why.

## Contribution Expectations

- Keep changes focused and easy to review.
- Use clear names and comments where helpful.
- Test the Bash script with valid and invalid inputs.
- Follow the Code of Conduct.
- Do not include passwords, access tokens, or other secrets.

## Reporting Bugs

When reporting a bug, include the steps to reproduce it, the expected result, and the actual result.
